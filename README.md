# Shannu Portfolio

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open the extracted folder in VS Code.
4. Open Terminal and run:

```bash
npm install
npm run dev
```

5. Open the localhost URL shown in the terminal.

## Personalise before publishing
Search in `src/main.jsx` for:
- `your-email@example.com` and replace it with your real email.
- GitHub and LinkedIn links and replace the generic profile URLs.
- Project titles, descriptions and technologies with your exact project details.
- Skill lists to remove anything you have not used yet.

Your uploaded profile photo is already included as `public/profile.jpeg`.

There is intentionally no Resume button or Resume section.
